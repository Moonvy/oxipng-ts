# 默认 `-o 2` 的自适应筛选预算

本文记录前一轮仅调整滤镜评分的结果。当前默认参数随后加入了解析预算，见 [5% 体积预算复测](O2-BUDGET.md)。

保留四种滤镜（NONE、SUB、Entropy、Bigrams）、最终压缩等级 11，以及原有匹配搜索和解析轮数。优化只减少合适图片的滤镜试压缩成本，不降低最终 Deflate 的搜索强度。

## 默认策略

颜色／位深／调色板转换始终沿用原来的筛选模型。完成这些转换后，满足下列条件才使用等级 2 的贪心编码器筛选滤镜，最终仍以等级 11 压缩胜出的滤镜：

- 快速筛选开启，最终压缩等级为 11，四种候选滤镜。
- 没有颜色转换候选的缓存评分，避免混用不同等级的评分。
- 输入为非交错 8 位，输出候选仍为 8 位 RGB/RGBA。
- 原始像素数据至少 64 KiB，且原压缩数据至少约为像素数据的八分之一。

其他图片使用原来的筛选等级。16 位、交错、索引色、小图和已高度压缩的图片受到更保守的处理；无法得到原压缩大小上限的 `--force` 和原始像素 API 也沿用原预算。

这是一项启发式预算调整，不能保证任意图片与旧默认输出逐字节一致。

## 实验选择

先测试减少滤镜、提前停止解析和更激进的匹配跳过，再测试筛选等级 1–6。

- 去掉 SUB：七张主样本体积保持不变，但生成 plasma 图增大约 16%，没有采用。
- 减少解析轮数、匹配深度或增加跳过：存在明显的个别图片体积退步，没有采用。
- 筛选等级 5、6：当前编码器的匹配路径使它们整体比等级 7 更慢，没有采用。
- 不加限制地使用筛选等级 2：主样本有收益，但 16 位和部分索引色／高压缩率夹具退步。最终将转换预算与滤镜预算分开，并收紧适用条件。

等级 2 保留比等级 1 更深的贪心匹配搜索，在筛选实验中与等级 1 选择相同的结果，耗时略高；最终保留这一较保守的档位。

## 最终复测结果

Apple M3 Pro，Node v26.7.0，2026-10-11。以下为各图同步 API 中位数之和；不含 CLI 启动。

| 范围 | 修改前 | 修改后 | 耗时减少 | 输出 |
| --- | ---: | ---: | ---: | --- |
| 原四张截图 | 5.629 s | 5.041 s | 10.45% | 逐字节一致 |
| 七张主样本 | 16.955 s | 15.625 s | 7.85% | 逐字节一致 |
| 主样本＋额外九图 | 20.201 s | 18.698 s | 7.44% | 逐字节一致 |

16 图总体积均为 8,351,597 B。逐图差异与三次原始耗时保存在 JSON 中。原四图总体积仍为 2,501,187 B，因此保留了先前测得的与 Rust `-o 2` 约 1.12% 的体积差距。

另检查 79 个至少 64 KiB 的 8 位夹具：所有前后输出 SHA-256 一致，总体积均为 3,000,585 B，且独立像素／APNG 校验通过。故意含错误 CRC 的 `fix_errors.png` 无法被独立解码，单独记录为跳过。夹具检查覆盖了初版预算曾出现退步的灰度转索引色、交错、已高度压缩和 RGBA 数据。

构建、类型检查及回归测试通过：20 个测试文件、560 项通过，4 项跳过。沿用前轮检查范围，排除已有断言失败／本环境监听端口受限的 `test/site-benchmark.test.js`；该网站基准测试未作为本次通过项。

构建后的实际 CLI（零预热、三次、各图最快值之和）：原四图 5.226 s，七图 15.665 s；七图中位数合计 15.881 s。全部 CLI 输出与当前 API 测量输出逐字节一致。原四图上一轮默认 CLI 为 5.638 s，本轮约减少 7.3%；这是不同实验轮次的比较，主要提速证据采用上表交替测量的 API 数据。

```sh
node benchmark/tune.mjs --corpus extended --runs 3 --warmup 1 \
  --candidates before-o2,current-o2 --output benchmark/default-o2-results.json
node benchmark/tune.mjs --corpus fixtures --runs 1 --warmup 0 \
  --candidates before-o2,current-o2 --output benchmark/default-o2-fixtures.json
npm run build:ts
node benchmark/presets.mjs --runs 3 --profiles baseline-o2 \
  --output benchmark/default-o2-cli.json
```

`before-o2` 在临时 bundle 内恢复原筛选模型，`current-o2` 直接使用当前生产实现。`fixtures` 对至少 64 KiB 的 8 位测试夹具检查输出；无法独立解码的原始文件会单独记录，输出解码／像素错误不会被跳过。夹具的一轮无预热耗时只用于检查，不能作为稳定提速证据。
