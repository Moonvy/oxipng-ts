Everything oxipng does — in TypeScript

Faithful port

Reductions, filter strategies and the evaluator mirror the Rust original, module for module.

Runs anywhere

Pure ESM/CJS with zero native dependencies. Works in modern browsers and Node.js ≥ 20.

CLI + library

A full command-line tool and an oxipng(image, options) function, plus a sync API.

Real reductions

Colour-type, palette, bit-depth, alpha and grayscale reduction, plus Adam7 interlacing.

9 filter strategies

None/Sub/Up/Average/Paeth plus MinSum, Entropy, Bigrams, BigEnt and a brute-force search.

Private by design

Files never leave your machine. The demo runs entirely in a Web Worker on your device.

Quickstart

CLI
npm install -g oxipng-ts

# Optimize in place
oxipng-ts -o 3 image.png

# Recursively, stripping safe-to-remove chunks
oxipng-ts -r -o 4 --strip safe ./assets
Library
import { oxipng, Options } from 'oxipng-ts';

const input = new Uint8Array(await file.arrayBuffer());

// Lossless, preset 3 (all transformations)
const optimized = await oxipng(input, Options.fromPreset(3));

// Or run it synchronously
import { oxipngSync } from 'oxipng-ts';
const fast = oxipngSync(input, Options.fromPreset(2));
