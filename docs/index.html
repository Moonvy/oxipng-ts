测量方法＋

测量口径随 benchmark 数据一同更新。

Rust 使用默认线程数；TypeScript 的各构建目标使用同一套 TypeScript 压缩核心，单线程执行。文件无法进一步缩小时保留原始字节。这里比较的是完整 PNG 优化流程，不只是 DEFLATE 内核。

结果取决于图片内容和运行环境。这组 CLI 实测不代表浏览器内的运行速度，也不与 API 基准计时混用。

03 / USAGE

安装与调用

支持 CLI、ESM 和 CJS。

ESM / CJS / CLI
TERMINAL
npm install -g oxipng-ts

# 优化单张图片
oxipng-ts -o 2 image.png

# 批量优化，输出到指定目录
oxipng-ts -r -o 3 --dir ./optimized ./assets
TYPESCRIPT
import { oxipng, Options } from 'oxipng-ts';

const input = new Uint8Array(
  await file.arrayBuffer()
);
const output = await oxipng(
  input, Options.fromPreset(2)
);
